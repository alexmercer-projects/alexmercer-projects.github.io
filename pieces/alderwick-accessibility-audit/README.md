# Alderwick Family Clinic accessibility audit

- **Category:** Accessibility
- **Label:** Concept demo
- **Year:** 2026

## What it is

A sample WCAG 2.2 Level AA accessibility audit report for a made-up clinic website, with a severity summary, the test method, 19 findings mapped to success criteria, before-and-after code fixes, a remediation plan and a note on fixing an inaccessible PDF form.

## Who it's for

Website accessibility audits and reports, accessibility fixes (alt text, contrast, labels, focus, keyboard traps), PDF accessibility work, and anyone who wants to see a sample report first.

## Key features

- Executive summary: 19 example issues by severity and by WCAG principle
- Scope and method: automated scan, keyboard, screen reader, zoom and reflow, contrast, documents
- Findings table with the success criterion, level, who is affected and the fix
- Before-and-after code for the most common fixes, with computed contrast ratios
- A remediation plan in priority order, and a PDF remediation checklist
- The whole report as a PDF

## Honesty

Concept demo. Alderwick Family Clinic and its website are made up, and nothing was actually tested, so every finding, count and estimate is an example. Not client work, and no certifications are claimed.
