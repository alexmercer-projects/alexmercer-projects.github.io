# Ridgeline Plumbing Co.: local SEO before and after

- **Category:** SEO
- **Label:** Concept demo
- **Year:** 2026

## What it is

A before-and-after demo of on-page local SEO for a made-up plumber in Fort Collins. A weak 3-page site is rewritten so titles, metas, headings, alt text, NAP consistency and tap-to-call are fixed. Both versions were scored with the same automated on-page check. No ranking results are claimed.

## Who it's for

Local SEO, "fix my Google listing / on-page SEO" and small-trades website improvement asks, especially when a buyer wants to see a before and after rather than a list of recommendations.

## Key features

- Scorecard for a 3-page site targeting "plumber" + "Fort Collins"
- Before site (missing titles, metas, H1s, alt text, inconsistent phone, no tap-to-call)
- After site (titles 30-60 characters with city and service, metas, one H1, alt text, one consistent 555 number, tap-to-call)
- Live HTML for both versions, plus a case-study sheet

## Honesty

Example data. Ridgeline Plumbing Co. is a made-up business with a placeholder address and phone. No real client, and no ranking, traffic or lead results are claimed. Only on-page checks are shown.
