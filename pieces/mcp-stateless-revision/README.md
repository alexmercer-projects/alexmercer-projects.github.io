## What it is

An unpublished technical article about the Model Context Protocol's 2026-07-28 revision, which moved the protocol from session-based to stateless. It explains what changed for people who build MCP servers, using the official specification and changelog at modelcontextprotocol.io.

## Who it's for

Developer-tools and protocol explainers, technical blogs, and "write this up for engineers" asks.

## Key features

- Plain walkthrough of the handshake going away, request-level metadata, and version errors
- Grounded in the official changelog rather than rumor
